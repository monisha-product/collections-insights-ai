# Dataset

Version 1 uses a public credit default dataset for demonstrating collections and recovery analytics.

The dataset contains customer demographic information, repayment history, bill amounts, payment amounts, and default indicators.

Future versions will incorporate richer loan and collections datasets to support recovery analytics and portfolio performance monitoring.

# Dataset

This project will use a public credit/loan default dataset to demonstrate collections analytics.

The dataset will be used to answer questions related to:
- Delinquency risk
- Repayment patterns
- Default indicators
- Customer segmentation
- Collections prioritization

No real customer or company data is used in this project.
