# Collections Insights AI - PRD

## Problem Statement

Collections and recovery teams often rely on analysts to answer portfolio and delinquency-related questions. This creates delays in decision-making and limits self-service analytics.

## Goal

Enable business users to ask natural language questions and receive instant, data-backed insights about collections performance, customer delinquency, recovery rates, and portfolio health.

## Target Users

* Collections Managers
* Recovery Managers
* Portfolio Analysts
* Operations Leaders

## Example Questions

* Which customer segments have the highest delinquency rates?
* What is the recovery rate by risk category?
* Which accounts should be prioritized for collection?
* What are the key drivers of default?

## Success Metrics

* Accurate SQL generation
* Response time under 5 seconds
* Business-friendly insights
* Reduced dependency on analysts

## Version 1 Scope

* Public loan/default dataset
* Natural language to SQL
* SQLite database
* Streamlit interface
* AI-generated insights
